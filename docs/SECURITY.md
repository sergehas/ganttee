# Security Policy

## Supported Versions

Only the latest release published on the VS Code Marketplace receives security fixes.

## Reporting a Vulnerability

Do not open a public issue for a security problem.

Report it privately with
[GitHub private vulnerability reporting](https://github.com/sergehas/ganttee/security/advisories/new).
Include:

- the Ganttee and VS Code versions,
- the steps to reproduce, with a minimal `.ganttee` file if possible,
- the impact that you expect.

The maintainers confirm receipt, investigate, and publish a fix and an advisory when the problem is
confirmed.
